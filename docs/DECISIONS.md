### 2026-09-29 — Бот даёт только каталог программ Школы коммуникаций
Требование ДПО: ссылка на общий каталог `hse.ru/edu/dpo/` ведёт слушателей к
программам других подразделений («даём рекламу другим, а не ведём лиды себе»).
Разрешён только `https://www.hse.ru/edu/dpo/?orgUnit=122999271`. Сделано в двух
местах: в FAQ все ссылки на общий каталог заменены или удалены, а в `SYSTEM_PROMPT`
обоих ботов — явный запрет. Проверено на модели: 6 из 6 ответов — каталог Школы.

### 2026-09-29 — Статический IP для ВМ `faqbot`
IP был динамическим и менялся при перезапуске ВМ (158.160.50.225 → 89.169.142.74 →
93.77.187.243). Релей Telegram пускает только `ALLOWED_IPS`, поэтому перезапуск ВМ
26.09 на три дня уронил Telegram-канал. Адрес зарезервирован (`faqbot-static-ip`)
по решению владельца, несмотря на доплату.

### 2026-09-22 — Telegram через посредника на Cloudflare Workers
`api.telegram.org` с сентября 2026 недоступен с любого российского сервера.
- **Перебор IP бесполезен — проверено.** Замер на четырёх ВМ в разных каталогах и
  подсетях (89.169.142.74, 89.169.146.175, 111.88.251.184, 89.169.157.225) дал одинаковый
  результат, вплоть до времени отсечки ~5,2 с: `github.com` → 200, `api.telegram.org` →
  HTTP 000. Фильтр смотрит на назначение, а не на источник. Скрипт «арендовать ВМ пачкой
  и искать непробитый IP» отклонён: результата не даст, а массовое создание ВМ выглядит
  для провайдера злоупотреблением и рискует аккаунтом, где живут все четыре проекта.
- **ВМ в Yandex Cloud kz1 (Казахстан)** — предложена в аналитической записке,
  **отклонена заказчиком** в тот же день: не хотим арендовать ВМ.
- **Выбрано:** Cloudflare Worker (`relay/`). Сервера нет, бесплатно. База, логи и
  обращения к модели остаются в РФ, релей ничего не хранит. Доступ к релею — только
  с IP нашей ВМ и только для нашего бота; без этих настроек релей отвечает 503
  (иначе это открытый прокси к Telegram для всех).
- Развёрнут 2026-09-23.

### 2026-09-18 — Правки интерфейса MAX-бота (замечания преподавателей и заказчика)
- «◀️ Назад в меню» — на каждом последнем сообщении: кнопки в MAX живут только на своём
  сообщении, без этого после оценки пользователь оставался без кнопок.
- «Задать вопрос Виртуальному помощнику (24/7)» → «❓ Задать вопрос помощнику»:
  на телефоне MAX обрезает подпись кнопки после ~26–28 символов.
- Подсказки «возможно, вы хотели спросить» — кнопки, а не текст: влияет на конверсию.

### 2026-09-15 — Метрика «Эскалация к менеджеру»
Требование заказчика. Эскалация = нажатие «📞 Связаться с менеджером». Пишется в
**отдельный** `escalations_log.csv`: в `questions_log.csv` нельзя — функция оценки
прицепила бы к такой строке оценку следующего ответа. Автоматический показ
контактов, когда бот не нашёл ответ, эскалацией не считается: это решение бота,
а не пользователя.

### 2026-09-11 — Мониторинг через дашборд, без влияния на бота
MAX-бот шлёт вопросы/оценки/эскалации на дашборд (`DASHBOARD_URL`) в фоновом потоке
с таймаутом 5 с. Если дашборд лежит — бот работает как раньше. Telegram-версия в
дашборд не шлёт.

### 2026-09-07 — Контакт менеджера — в MAX, а не в Telegram
Кнопка «Связаться с менеджером» отправляла людей в заблокированный Telegram
(@dposchoolcomm). У личных аккаунтов MAX нет коротких ссылок, поэтому указан номер
телефона для поиска: аккаунт ДПО — +7 916 211 19 67.

### 2026-09-06 — MAX — основной канал, Telegram — дополнительный
Telegram блокируется в РФ, до бота перестали доходить пользователи. Бот перенесён
в MAX один в один, переписан только транспортный слой (`maxbot/`). Оба бота — на
одной ВМ независимыми контейнерами. Детали Bot API MAX — [maxbot/README.md](../maxbot/README.md).
- Домен API — `botapi.max.ru`, а не рекомендуемый документацией `platform-api2.max.ru`:
  у второго сертификат российского УЦ, с ВМ TLS не проходит.
- Свой тонкий клиент на `requests` вместо библиотеки `maxapi` — чтобы управлять доменом.

### 2026-06-22 — Переезд в Yandex Cloud, модель Qwen вместо OpenAI
Бот перенесён со стороннего VPS (206.251.48.91, оставлен остановленным как откат;
там же чужие контейнеры — не трогать) в Yandex Cloud: данные должны обрабатываться
и храниться в РФ (152-ФЗ). OpenAI заменён на Qwen 3.6 35B в Yandex AI Studio.
- Qwen — модель «с размышлениями»: обязательно `reasoning_effort="none"`, иначе
  она тратит весь лимит на размышления и возвращает пустой ответ.
- Модели Qwen в AI Studio включаются **для каждого каталога отдельно**, иначе 403.

## Открытые вопросы (решают юристы, не техника)

- **ч. 8 ст. 10 149-ФЗ** — запрет иностранных мессенджеров при выполнении гос./муниципального
  задания. Если заключение отрицательное — Telegram-канал выключается
  (`cd /opt/faqbot && sudo docker compose stop`), остаётся MAX.
- **Уведомление РКН о трансграничной передаче** — ОАЭ (Telegram) и США (Cloudflare;
  у Cloudflare распределённая сеть, страна обработки запроса заранее неизвестна).
- Схема потоков данных и политика обработки ПДн — привести к фактической архитектуре.
